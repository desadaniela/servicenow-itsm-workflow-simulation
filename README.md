# ServiceNow Ticket Management Workflow

## Objective
The purpose of this project was to gain hands-on familiarity with core ITSM ticketing operations in ServiceNow. I walked through the full lifecycle of a service request to practice navigating the platform UI, managing ticket states, and documenting support steps properly.

---

## What I Practiced
* **Navigating ServiceNow Workspaces:** Accessing request forms, task lists, and ticket fields.
* **Ticket Creation & Routing:** Setting up incident tasks, assigning priority levels, and routing to the `IT Securities` group.
* **Work Note Auditing:** Updating ticket status to *Work in Progress* and writing clear internal notes for audit trails.
* **Ticket Closure:** Documenting resolution steps and transitioning the task to *Closed Complete*.
